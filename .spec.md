# 📋 Contrato SHDD: Ingesta de URL de texto con Jina Reader e Índice de Temas (ISS-030)

### 🎯 Target Files Permitidos
Lista blanca estricta de archivos que el sub-agente tiene permiso de modificar o crear:
- [NEW] `src/core/web_scraper.py`
- [MODIFY] `src/core/script_generator.py`
- [MODIFY] `src/ui/tab_fuente.py`
- [NEW] `test/test_web_scraper.py`

### 🚫 Acciones Prohibidas (Guardrails)
- **NO instalar dependencias nuevas:** Usar `urllib.request` estándar de Python para llamar a `https://r.jina.ai/{url}`.
- **NO usar playwright ni bs4** en `web_scraper.py`.
- **NO modificar la lógica actual de video/audio** en `tab_fuente.py` ni `script_generator.py`, solo AGREGAR el soporte para "URL Web (Artículo/Texto)".

### 🛠 Instrucciones de Implementación

1. **`src/core/web_scraper.py`**:
   Crear una función `extract_text_from_url(url: str) -> str`. Deberá hacer un request `GET` a `https://r.jina.ai/{url}`. Capturar errores (ej: `urllib.error.URLError`) y devolver el texto Markdown crudo, o levantar una excepción clara.

2. **`src/core/script_generator.py`**:
   Crear `generate_topic_index_from_text(texto_fuente: str) -> list[dict]` que pida al LLM los 5 a 10 temas principales, pero la estructura JSON debe ser:
   `{"data": [{"tema": "Título", "preview": "Un pequeño resumen o cita literal..."}]}`

3. **`src/ui/tab_fuente.py`**:
   - En `modo_ingesta = st.radio("origen", ["Archivo multimedia", "URL de YouTube", "URL Web (Artículo/Texto)", "Texto directo"] ...)`
   - Si se elige `URL Web`, pedir el input con `url_input = st.text_input(...)`. Setear `source_type = "web_text"`.
   - Si `source_type == "web_text"`, al clickear transcribir, usar `extract_text_from_url(url)` en el `progress_box`. Luego construir el resultado (md_content) directamente usando el markdown extraído.
   - En el renderizado del índice (`topic_index = st.session_state.get("topic_index")`), en el loop, verificar si tiene `.get("preview")` en vez de `timestamps` y renderizar `st.markdown(f"**{tema_txt}**<br>_{preview}_", unsafe_allow_html=True)`.

4. **`test/test_web_scraper.py`**:
   Crear un test simple usando mock (con `unittest.mock.patch` de `urllib.request.urlopen`) para evitar llamados reales de red lentos o inestables en el CI.

### 🧪 Quality Gate Determinista
Comando exacto de terminal para auditar y verificar el éxito del contrato:
`pytest test/test_web_scraper.py`
